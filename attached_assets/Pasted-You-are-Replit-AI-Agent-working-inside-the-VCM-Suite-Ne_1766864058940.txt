DSP WORKLET REQUIREMENTS
Implement a stereo delay line with fractional delay:
- Sample rate: from context
- Max delay buffer: e.g., 200ms
- Delay time per-sample = baseDelay + modSignal (clamped)
- Interpolation: linear is acceptable for MVP, but avoid clicks via smoothing.
- Use one-pole smoothing on parameters:
  smooth = smooth + a*(target-smooth), with a ~ 0.001–0.01 depending on param.

Mod signal:
- wander: random walk updated every N samples (e.g., every 256 samples), bounded [-1,1]
- flutter: sine + small noise
- combine: mod = rangeMs * (wow*wander + flutter*sin + randomNoise*small)
- independent L/R seeds for width
- For sync mode: convert BPM to Hz: hz = bpm/60 * multiplier

Saturation:
- waveshaper curve: tanh-ish approximation
- pre-gain = 1 + drive*X
- post lowpass controlled by tone
- Keep it subtle by default.

Latency behavior:
- In low-latency mode, set baseDelay minimum to 5ms and range <= 5ms, disable wander/pitchy modulation.
