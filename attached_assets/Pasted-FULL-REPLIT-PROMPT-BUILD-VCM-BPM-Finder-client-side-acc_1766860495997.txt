6) BPM DETECTION REQUIREMENTS (lib/audio/bpm.ts)
========================================
Implement BPM detection using deterministic signal processing (no AI, no external APIs).

Must be fast and reasonably accurate.
Approach (implement exactly this style):

A) Decode audio to AudioBuffer
B) Convert to mono Float32Array
   - average L/R if stereo
C) Downsample for speed (target sampleRate ≈ 11025 or 16000)
D) Build onset/energy envelope:
   - frameSize ~ 1024 (after downsample)
   - hopSize ~ 512
   - for each frame compute RMS energy
   - compute positive energy flux: max(0, rms[i] - rms[i-1])
   - smooth with a short moving average window (e.g., 4–8 frames)
E) Autocorrelation (or peak-period detection) on the onset envelope:
   - Compute correlation for lag range that corresponds to 60–200 BPM by default
   - Convert lag -> BPM = 60 * envelopeSampleRate / lag
F) Peak picking:
   - Find top peaks (at least 5)
   - Merge near-duplicates (within 1–2 BPM)
   - Return sorted candidates with scores

G) Normalize and choose primary BPM:
   - Choose the highest score BPM after normalization
   - If primary BPM < 60, consider doubling into range
   - If primary BPM > 200, consider halving into range
   - Return primary plus alt candidates

H) Confidence:
   - High: topScore / secondScore >= 1.35 and topScore absolute above threshold
   - Medium: ratio 1.15–1.35
   - Low: ratio < 1.15 OR very low absolute scores
   Implement this deterministically and return { label, ratio, scores }.

Output type:
export type BpmCandidate = { bpm: number; score: number; };
export type BpmResult = {
  primaryBpm: number;
  confidence: "High" | "Medium" | "Low";
  candidates: BpmCandidate[]; // sorted desc, unique-ish
  halfTime?: number;
  doubleTime?: number;
  debug?: { ratio: number; envelopeRate: number; };
};

Export function:
export async function detectBpmFromArrayBuffer(arrayBuffer: ArrayBuffer): Promise<BpmResult>

Performance rules:
- If audio is very long, analyze only the first N seconds (default 90s) to keep it quick.
- If duration < 8s, set confidence Low automatically.
