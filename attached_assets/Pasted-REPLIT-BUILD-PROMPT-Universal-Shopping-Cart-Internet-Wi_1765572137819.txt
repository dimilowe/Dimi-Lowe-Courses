Step 3 — Cart Identity (Anon + Logged-In Merge)
Implement a server-owned cart resolver.
Rules:
If logged in → resolve/create one active default cart for user_id
If anonymous → resolve/create one active default cart for anon_session_id stored in httpOnly cookie
If user logs in and has anon cart → merge items into user cart, then delete or mark anon cart as merged
Acceptance:
Anonymous user can save item, refresh, still see it
After login, previously saved anon items appear in the logged-in cart
Step 4 — OpenGraph Fetcher (Server-Side)
Implement a secure metadata fetcher used when saving URLs.
Requirements:
Fetch only http/https URLs
Block localhost / private IP ranges / internal hostnames (SSRF protection)
Limit response size and timeout
Parse OpenGraph:
og:title, og:image, og:description, og:site_name
Fallback to <title> if OG title missing (optional)
Store og_raw for debugging (optional)
Acceptance:
Common product pages return title + image
If fetch fails, tool still saves URL with minimal fields and allows manual editing
