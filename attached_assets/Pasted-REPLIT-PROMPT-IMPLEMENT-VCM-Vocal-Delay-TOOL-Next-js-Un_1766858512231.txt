4) AUDIO ENGINE REQUIREMENTS (vocalDelayEngine.ts)
========================================
Implement a class that builds the node graph and exposes setters:

- setTempo(bpm, division)
- setFeedback(value)
- setMix(value)
- setPingPong(enabled)
- connectInput(node)
- connectOutput(node) OR expose input/output GainNodes

MUST implement real ping-pong:
Two delay nodes (L/R) with cross-feedback when pingPong = true.
When pingPong = false, switch to self-feedback per channel (no bounce).

Delay time mapping:
quarter_ms = 60000 / bpm
multipliers:
- 1/4 => 1.0
- 1/8 => 0.5
- 1/16 => 0.25
delaySeconds = (quarter_ms * multiplier) / 1000

Mix:
Equal-power crossfade:
dry = cos(x * pi/2)
wet = sin(x * pi/2)

Smoothing:
Use setTargetAtTime for:
- delayTime
- gain changes
timeConstant ~ 0.01

Limits:
- bpm clamp 40–240
- feedback clamp 0–0.95 ALWAYS

Node graph (realtime):
input -> dryGain -> masterGain -> destination
input -> delayL
input -> delayR

Output:
delayL -> merger left
delayR -> merger right
merger -> wetGain -> masterGain

Feedback routing:
If pingPong ON:
delayL -> fbL -> delayR
delayR -> fbR -> delayL
self loops off

If pingPong OFF:
delayL -> selfLoopL -> delayL
delayR -> selfLoopR -> delayR
cross loops off

Implement switching by keeping both loop routes connected but controlling loop gains:
- cross loop gains: fbL/fbR
- self loop gains: selfLoopL/selfLoopR
When pingPong ON: cross = feedback, self = 0
When pingPong OFF: cross = 0, self = feedback
