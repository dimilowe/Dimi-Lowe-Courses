KEY DETECTION ALGORITHM (DO THIS)
Use librosa chroma features + a standard key profile correlation.

1) Load normalized mono WAV (22050Hz).
2) Compute chroma:
   - chroma = librosa.feature.chroma_cqt(y=y, sr=sr) OR chroma_stft
3) Aggregate into a pitch class energy vector:
   - pc = chroma.mean(axis=1)  // 12 bins
4) Compare against Krumhansl-Schmuckler key profiles (major/minor templates)
   - For each of 12 tonics:
     - rotate template
     - compute correlation score (e.g., cosine similarity)
   - Choose best major/minor as dominant key.
5) Confidence:
   - softmax over top scores OR (best - second_best) normalized
   - Output 0..1
6) Alternate candidates:
   - return top 5 keyLabels with normalized confidences

MODULATIONS (SIMPLE, USEFUL)
Detect key changes by windowed analysis:
- window size: 8s
- hop: 4s
For each window:
- compute chroma mean and key correlation
- create segment list by merging adjacent windows if same keyLabel and confidence >= 0.45
- discard tiny segments < 6s unless confidence >= 0.65
Return modulations segments.

NOTE: This does not need to be perfect. It needs to be practical.

EDGE CASE HANDLING
- If confidence is low (<0.35), display: “Low confidence — try isolating the instrument or using a cleaner excerpt.”
- If audio is percussive/no pitch content, confidence will be low. That’s okay.
