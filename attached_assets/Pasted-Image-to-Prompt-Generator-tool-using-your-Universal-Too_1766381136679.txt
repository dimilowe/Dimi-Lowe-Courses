- Returns ONLY:
{ "id": "...", "title": "...", "prompt": "..." }
- Must re-use the same analysis approach but only produce that specific variant prompt.

MODEL INSTRUCTIONS (IMPORTANT):
When preserveLayout=true:
- DO NOT change camera angle, framing, crop, subject placement, or spatial relationships.
- MUST explicitly describe spatial layout (foreground/midground/background).
- MUST include layout_map (not null).
- All variants must preserve identical composition; only wording, style, or “remix story flavor” may change (but layout remains).
When preserveLayout=false:
- layout_map must be null.
- Prompts can be more flexible and vibe-based.

When keepTextExact=true:
- If the image contains text (signs, posters, UI), do NOT invent new text.
- Describe text as “[exact text]” only if clearly legible; otherwise use placeholders like “[unreadable small text]”.
- Focus on typography/layout instead of hallucinating content.

Safety / correctness:
- Do not guess a person’s identity.
- Do not add brand names unless clearly visible and necessary to describe (keep minimal).
- If the image is abstract, provide best-effort description and prompts.
