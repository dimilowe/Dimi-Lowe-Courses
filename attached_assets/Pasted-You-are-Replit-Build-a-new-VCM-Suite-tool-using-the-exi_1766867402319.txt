MELODY POST-PROCESSING ALGORITHM (DO THIS EXACTLY)
Inputs: note_events from Basic Pitch with (start_time, end_time, pitch_midi, amplitude/confidence if present)

Step 1: Filter by plausible vocal range (soft bias, not hard cut)
- Preferred range: 80Hz–1100Hz (approx E2–C#6)
- Convert pitch_midi to Hz and downweight outside range.

Step 2: Remove obvious junk notes
- Drop notes with duration < 0.06s
- Drop notes with extremely low confidence/amplitude if field exists

Step 3: Select monophonic “active note” over time
Use time slicing at 20ms frames:
- For each frame, find all notes active at that time.
- If none, output silence for that frame.
- If multiple, score each candidate:
  base = confidence_or_amplitude (if missing, use 1.0)
  jump_penalty = abs(candidate_pitch - prev_pitch) (prev_pitch from last chosen frame) * 0.15
  short_penalty = 0.25 if candidate_note_duration < 0.12 else 0
  range_penalty = 0.25 if outside preferred vocal range else 0
  score = base - jump_penalty - short_penalty - range_penalty
Pick candidate with max score.
Add hysteresis:
- If current active note is still present and the best candidate is only better by < 0.10 score, keep current.

Step 4: Convert framewise chosen pitch to note events
- Merge consecutive frames with same pitch into events
- Merge if gap < 0.06s and pitch equal
- Drop final events < 0.08s

Step 5: Write melody_notes.csv
Columns:
start_time_s,end_time_s,midi_note,frequency_hz,confidence

Step 6: Write pitch_curve.csv
For each 20ms frame:
time_s,frequency_hz,midi_note_float,confidence
If using only discrete pitch, midi_note_float can equal midi_note.

Step 7: Create melody.mid
- One track monophonic
- Preserve timing precisely
- If pitch bends available from model_output, you MAY include; otherwise omit (acceptable).
- Ensure MIDI imports cleanly in DAWs.

Step 8: Sonify to melody_preview.wav
- Use the same approach as your existing pipeline (Basic Pitch already can sonify, but it may sonify full output; here you must sonify the melody.mid).
- If you already have a MIDI-to-WAV render helper, reuse it.
- If not, use a lightweight method available in your environment (keep it simple; don’t add heavy synth deps).
- If sonification is too complex to do reliably, fall back to NOT generating wav and return wavUrl as empty string — but try hard to support it since audio-to-midi already does.
