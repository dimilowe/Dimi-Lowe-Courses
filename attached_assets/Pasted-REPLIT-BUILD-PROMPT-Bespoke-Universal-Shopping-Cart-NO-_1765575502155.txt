Step 2 — Identity (Anon + Logged-in Merge)
Create server helper resolveCart():
If logged in: find or create cart for user_id
If anon: find or create cart for anon_session_id stored in httpOnly cookie
If user logs in and anon cart exists: merge items into user cart (no duplicates by url unless you allow duplicates), then delete/mark anon cart
Cookie:
name: usc_anon
httpOnly, secure in prod, sameSite lax, long expiry (30–180 days)
Step 3 — OpenGraph Fetcher (Secure SSRF-Protected)
Implement server-only function fetchOpenGraph(url) with:
Only allow http/https
Reject localhost, private IPs, link-local, metadata IPs (IPv4 + IPv6)
Enforce timeout (e.g. 4–6s)
Enforce max response size (e.g. 1–2MB)
Follow redirects safely (cap at 3)
Parse:
og:title, fallback to <title>
og:description / description
og:image
og:site_name
Return { title, description, image_url, site_name, og_raw }
If fetch fails:
still allow saving the URL with minimal fields
