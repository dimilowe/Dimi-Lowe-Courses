GOAL
Build a new SEO tool page: WEBP to JPG Converter (also supports WEBP → PNG). This solves the common issue where images downloaded from the internet save as .webp. Users should be able to upload/drop a .webp file and it auto-converts immediately (no extra button) and offers download buttons.

HARD REQUIREMENTS
- 100% client-side conversion (no server/API route). Do NOT upload or store files.
- Works in modern browsers (Chrome/Safari/Firefox). Use canvas re-encode.
- Auto-convert on file selection (and on drop).
- Show original preview and converted preview.
- Provide “Download JPG” and “Download PNG” buttons.
- JPG quality presets: Small (0.7), Balanced (0.85), High (0.95) — default Balanced.
- Allow multi-file batch drop/upload:
  - Convert all
  - Show a list with per-file status, preview, file name, original size, converted size
  - Individual download buttons per item
  - “Download All as ZIP” (zip contains converted JPGs by default; also offer a toggle to zip as PNGs).
- Include strong error handling (non-image uploads, corrupted files, huge files).
- Add a toggle: “Auto-download after conversion” (default ON). When ON: after conversion completes for a file, auto-trigger download for the default format (JPG).
- Add privacy copy: “Runs in your browser. We don’t upload your files.”
- Page must follow the Universal Tool Template structure: metadata, SoftwareApplication JSON-LD, FAQPage JSON-LD, hero, tool client component, SEO content sections, features grid, FAQ accordion, ExploreMoreTools.
- Use Tailwind for styling. Match the same layout vibe as the template.
- No external paid APIs.
- Use only lightweight dependencies. You MAY install “jszip” for the ZIP feature (allowed). If installing, update package.json accordingly.

TECHNICAL IMPLEMENTATION DETAILS
- Use URL.createObjectURL for previews and cleanup URLs to avoid memory leaks.
- For conversion:
  - Load image via createImageBitmap when available (faster), fallback to Image().
  - Draw to canvas at natural width/height.
  - For JPG: canvas.toBlob("image/jpeg", quality)
  - For PNG: canvas.toBlob("image/png")
- Animated WEBP:
  - If the browser decodes only first frame, warn user: “Animated WEBP will convert to a single frame.”
  - Detect animation if possible (optional). If too complex, show note in FAQ + small UI note.
- ZIP:
  - Use JSZip to add files; name outputs with same base filename + .jpg or .png.
  - Provide a single “Download All as ZIP” button when there is at least one Ready item.
