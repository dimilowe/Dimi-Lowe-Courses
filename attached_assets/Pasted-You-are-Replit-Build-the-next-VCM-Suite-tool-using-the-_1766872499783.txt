CHORD INFERENCE ALGORITHM (PRACTICAL, NOT A RESEARCH PROJECT)
Work from note events.

Inputs: list of notes:
- start_time_s
- end_time_s
- midi_pitch (0-127)
- velocity (optional)

1) Build analysis windows:
- windowSec = 2.0
- hopSec = 1.0
(These settings produce usable chord changes without being too jittery.)

2) For each window:
- collect “active notes” where note overlaps window by at least 0.2s
- weight each note by overlap duration (and optionally velocity)
- convert pitches to pitch classes (0..11) and aggregate weights into 12-bin vector pc[12]

3) Candidate chord templates (start simple, high-leverage):
Triads:
- maj: 0,4,7
- min: 0,3,7
- dim: 0,3,6
- aug: 0,4,8
Sevenths:
- maj7: 0,4,7,11
- min7: 0,3,7,10
- dom7: 0,4,7,10
- m7b5: 0,3,6,10
Suspended:
- sus2: 0,2,7
- sus4: 0,5,7
Optional add-ons if easy:
- add9: 0,4,7,2 (or 14 mod 12)
- 6: 0,4,7,9 (maj6) and 0,3,7,9 (min6)

4) Score each root (12) + quality template:
- rotate template to the root
- compute score:
  - template_present = sum(pc[n] for n in chord_tones)
  - template_missing_penalty = small penalty if pc for chord tones are weak
  - non_chord_penalty = penalty for strong pc bins not in chord tones (to reduce “everything is Cmaj7”)
A robust and simple scoring function:
score = (sum(pc[tone]) / (sum(pc)+1e-9)) - 0.35*(sum(pc[non_tones])/(sum(pc)+1e-9))
Then clamp 0..1.

5) Choose best chord per window.
Compute confidence:
- bestScore vs secondBest:
  confidence = sigmoid((best - second)*8)
Also damp confidence if total energy is too low (not enough pitched notes).

6) Smooth into segments:
- Merge consecutive windows if same chordLabel AND confidence >= 0.45
- If chordLabel flips for 1 window then returns, treat as noise and merge (simple hysteresis)
- Drop segments shorter than 1.5s unless confidence >= 0.7

7) Output chords as segments:
{startSec, endSec, chordLabel, confidence, notes:[...pitch names]}

8) Optional: MIDI chord track
Create a MIDI file where each chord segment is rendered as block chord notes (root position) in a fixed octave:
- root around C3–B3 range
- triad/seventh as simultaneous notes at segment start, note-off at segment end
This makes it easy to drag into a DAW.

EDGE CASES / HONEST LIMITATIONS (MUST DISPLAY)
- Full mixes with bass + melody + pads can confuse chord inference
- Inversions may be labeled as the “root chord” even if bass implies slash chords (we’re not doing slash chords yet)
- Very short clips = unstable results
- Drums/no pitched content = low confidence
- Complex jazz harmony = best-effort
