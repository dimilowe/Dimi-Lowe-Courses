ENGINE DETAILS (IMPLEMENT EXACTLY)

1) Delay time mapping:
quarter_ms = 60000 / bpm
division multipliers:
- 1/4 => 1.0
- 1/8 => 0.5
- 1/16 => 0.25
delaySeconds = (quarter_ms * multiplier) / 1000

2) Node graph:
input -> dryGain -> masterGain -> destination
input -> delayL
input -> delayR

PingPong ON:
delayL -> fbL -> delayR
delayR -> fbR -> delayL
delayL -> merger left
delayR -> merger right
merger -> wetGain -> masterGain

PingPong OFF:
Use self loops:
delayL -> selfLoopL -> delayL
delayR -> selfLoopR -> delayR
Set cross-feedback gains to 0; selfLoop gains to feedback
Output still stereo (L delay to L, R delay to R), but repeats are not bouncing.

3) Mix:
Use equal-power crossfade:
dry = cos(x*pi/2)
wet = sin(x*pi/2)

4) Smoothing:
Use setTargetAtTime for delayTime and gains with timeConstant 0.01

5) Limits:
feedback <= 0.95 always
bpm 40–240
