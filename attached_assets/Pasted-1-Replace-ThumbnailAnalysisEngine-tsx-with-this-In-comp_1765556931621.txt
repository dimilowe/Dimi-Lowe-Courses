This is basically your AI coach page turned into a reusable engine:
ThumbnailCoachClient still handles the drag-and-drop + API call.
Title / description pull from the CMS tool (tool.name, tool.description).
engineConfig.variant lets you switch labels per platform if you want.
2. Make sure the engine is registered
In lib/engineRegistry.ts (or wherever ENGINE_REGISTRY / ENGINE_COMPONENTS live), ensure you have:
import dynamic from "next/dynamic";

export const ENGINE_COMPONENTS = {
  // ...
  "thumbnail-analysis": dynamic(
    () => import("@/components/engines/ThumbnailAnalysisEngine")
  ),
  // ...
};

export const ENGINE_REGISTRY = {
  // ...
  "thumbnail-analysis": {
    label: "Thumbnail Analysis",
    hasAi: true,
    heavyMode: "single",
  },
};
(Names might differ slightly in your repo; match your existing pattern.)
3. Wire each thumbnail tool to this engine
For each of these tools in the Content tab:
ai-thumbnail-coach
youtube-thumbnail-analyzer
instagram-thumbnail-analyzer
facebook-thumbnail-analyzer
twitter-thumbnail-analyzer
tiktok-thumbnail-analyzer
linkedin-thumbnail-analyzer
pinterest-thumbnail-analyzer (if you keep it)
Set:
Engine → thumbnail-analysis
In the CMS JSON for engine_config (or whatever field holds engine config), add:
{
  "engine": "thumbnail-analysis",
  "variant": "youtube"
}
or "instagram", "tiktok", etc per tool.
Once those three steps are done, all those URLs will render with the same premium AI YouTube Thumbnail Coach layout, just with different titles/variants.
