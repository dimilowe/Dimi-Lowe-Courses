ROLE
You are a senior full-stack engineer building a bespoke consumer-facing tool inside an existing Next.js app.

GOAL
Build Amazon Dupe Finder:
A tool that takes an Amazon product URL and returns cheaper visually similar products with affiliate links.
PAGE LOCATION
Create a new page at:
/tools/amazon-dupe-finder/page.tsx
This page:
uses the standard site layout
is tagged to Shopping Cloud
does NOT use CMS blocks
USER FLOW (V1)
User pastes an Amazon product URL
Clicks Find Cheaper Dupes
Tool:
extracts product title, image, price
finds 3–5 cheaper similar items
Results render immediately
No login required
INPUT
Amazon product URL (required)

must contain amazon.com
must include a product identifier (ASIN)
Show friendly error messages if invalid.
OUTPUT (FREE – FULL VALUE)
Original Product Card
Product image
Product title
Original price
“View on Amazon” (affiliate link)
Dupe Results (3–5 items)
Each dupe shows:
Product image
Title
Price
% cheaper than original
“Similarity” label (text-based, not ML-heavy)
Affiliate link
CORE LOGIC (IMPORTANT)
1. Product Parsing
Create a utility:
parseAmazonProduct(url) → {
  title,
  image,
  price,
  category,
  keywords
}
Use:
URL parsing
lightweight fetch / metadata extraction
graceful fallback if price is unavailable
2. Dupe Matching (Marketplace-Agnostic)
Create a generic interface:
findDupes(product, market = "amazon")

use product keywords + category
return cheaper similar items
NOT be hardcoded to Amazon logic

findDupes(product, "aliexpress")

No heavy ML yet.
Similarity score based on:

visual proximity (image alt/title similarity)

"Very Similar"
"Similar"
"Inspired"
